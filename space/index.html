02

Routing architecture

Owned compute first. Fallback with an audit trail.

The router separates logical-model choice from provider traversal. It records skipped, failed, cooled-down, and successful attempts instead of hiding the path behind a single answer.

Priority 01 · sovereign Operator-owned compute First route when explicitly configured and reachable. `sovereign: true` is reserved for this class.
Priority 02 · hosted Configured free tier Used only after the owned route is unavailable or unsuitable. Always labeled `sovereign: false`.
Priority 03 · paid Bounded paid fallback Last resort with an explicit cost basis, attempt record, and provider-class provenance.

Decision path

A deterministic classifier chooses the logical route; independent runtime policy decides which configured provider may serve it.
